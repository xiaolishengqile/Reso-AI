# 云上原野世界地图原型

面向电脑浏览器的二维串联岛屿地图原型。地图使用手绘浮岛底图和原生二维画布交互，玩家从家庭小屋出生，按顺序前往爬山岛和工作岛。

## 本地运行

```sh
npm install
npm run dev
```

浏览器打开终端显示的本地地址即可体验。

## 操作方式

- 进入地图前先选择男生或女生旅人。
- 使用方向键或 `W/A/S/D` 移动角色。
- 点击道路可以自动前往目标位置。
- 将鼠标移动到发光地点上可查看地点信息。
- 角色靠近地点后，点击地点可打开入口反馈。
- 完成爬山演示后，通往工作岛的桥才会开放。

## 当前内容

- 家庭小屋、爬山岛、工作岛三个串联场景。
- 手绘浮岛底图、男女角色选择、正侧背方向外观、点击移动和键盘移动。
- 工作岛锁定云雾、桥梁通行限制和爬山完成解锁。
- 角色移动速度为每秒 145 个地图单位；遇到阻挡会滑动或自动停止。

当前版本聚焦世界地图体验，独立地点内部场景使用轻量入口面板演示。
