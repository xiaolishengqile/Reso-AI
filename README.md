# 人生群岛关系旅程

面向电脑浏览器的二维关系剧情体验。玩家会与同一位同行者依次经历雾谷、爬山、工作、吃饭、同居、金钱、社交、旅行、未来和心愿十座岛。

## 本地运行

运行环境要求 Node.js 22.12 或更高版本。项目使用 Node.js 22 的原生环境变量文件加载、请求取消与服务端接口能力。

```sh
npm install
cp .env.example .env
# 编辑 .env，填写 TOKENDANCE_API_KEY
npm run dev
```

浏览器打开终端显示的本地地址即可体验。

`TOKENDANCE_API_KEY` 仅由服务端读取；浏览器只向同源 `/api/icebreaker` 提交七组正式证据，密钥不会进入页面、构建产物或浏览器存储。请勿将真实密钥提交到仓库。

生产环境先构建，再启动同源服务：

```sh
npm run build
npm start
```

同源服务同时提供构建后的页面、视频文件和破冰接口。视频支持浏览器拖动播放所需的单段字节范围请求。

## 破冰生成服务

完成爬山岛七组正式问题后，地图右上角会出现“生成破冰话术”。生成只在用户点击后发生；服务端要求模型返回七个固定顺序的内部写作节点，通过中文比例、单段、字数、诊断与敏感属性校验后，将节点拼成一个 150～250 字自然段。浏览器收到的响应仍只包含虚拟昵称和话术正文，成功结果按答案签名缓存在本地。

接口默认按连接的真实套接字地址执行每分钟 5 次的固定窗口限制，并将上游生成并发限制为 2。可以通过以下变量调整保守默认值：

- `ICEBREAKER_RATE_LIMIT_MAX_REQUESTS`：每个来源在窗口内允许的请求数。
- `ICEBREAKER_RATE_LIMIT_WINDOW_MS`：固定窗口毫秒数。
- `ICEBREAKER_MAX_CONCURRENT_GENERATIONS`：全局上游生成并发数。

服务默认不信任 `X-Forwarded-For` 等转发地址头。部署在反向代理后时，应在确认代理会清洗客户端自带转发头后，通过 `createAppHandler` 的 `getSourceId` 注入可信来源解析策略；否则所有请求会按代理套接字地址共享限额。限流或并发满载时接口返回稳定的 429 响应和 `Retry-After`。

## 操作方式

- 进入地图前先选择男生或女生旅人。
- 使用方向键或 `W/A/S/D` 移动角色。
- 点击道路可以自动前往目标位置。
- 将鼠标移动到发光地点上可查看地点信息。
- 角色靠近地点后，点击地点可打开入口反馈。
- 完成当前剧情岛后，通往下一岛的桥和云雾才会开放。

## 当前内容

- 雾谷记录用户资料，爬山岛保留原有七组正式选择。
- 工作至未来七座岛各包含六组情侣高频冲突选择，共形成四十九组剧情证据。
- 每次选择先展示同行者反馈，再自然承接下一事件；进度刷新后可恢复。
- 首次完整游玩形成正式证据，普通重玩不会覆盖首次答案。
- 心愿岛按用户行为、伴侣期待和共同规则生成十二章节的可解释画像。
- 爬山岛完成后可按需调用服务端人工智能生成虚拟匹配对象与破冰话术；前端不保存服务密钥。
- 心愿岛画像仍由浏览器本地生成，不依赖破冰服务是否可用。
- 十座岛使用顺序门禁、逐岛云雾和独立主题地形。

画像描述关系特征和相处方式，不推断外貌、敏感属性或心理诊断。
