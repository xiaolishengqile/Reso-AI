# 云上原野世界地图原型

面向电脑浏览器的二维半开放世界地图原型。地图使用代码生成的低多边形地形与手绘风格界面，玩家可以在浮空大陆上移动、探索并点击地点入口。

## 本地运行

```sh
npm install
npm run dev
```

浏览器打开终端显示的本地地址即可体验。

## 操作方式

- 使用方向键或 `W/A/S/D` 移动角色。
- 将鼠标移动到发光地点上可查看地点信息。
- 角色靠近地点后，点击地点可打开入口反馈。

## 当前内容

- 云脊山、风语林、星痕遗迹三个可交互地点。
- 正交俯视相机、平滑跟随、障碍碰撞与地点距离判断。
- 低多边形浮岛、河流、桥梁、森林、遗迹、云层和纸张质感界面。

第一版只验证世界地图体验，独立地点内部场景将在后续阶段接入。

## 验证
