# 云上原野世界地图原型

面向电脑浏览器的二维半开放世界地图原型。地图使用统一的手绘浮岛底图和原生二维画布交互，玩家可以在浮空大陆上移动、探索并点击地点入口。

## 本地运行

```sh
npm install
npm run dev
```

浏览器打开终端显示的本地地址即可体验。

## 操作方式

- 进入地图前先选择男生或女生旅人。
- 使用方向键或 `W/A/S/D` 移动角色。
- 点击道路可以自动前往目标位置。
- 将鼠标移动到发光地点上可查看地点信息。
- 角色靠近地点后，点击地点可打开入口反馈。

## 当前内容

- 云脊山、风语林、星痕遗迹三个可交互地点。
- 手绘浮岛底图、男女角色选择、正侧背方向外观、点击移动和键盘移动。
- 浮岛边界与地标碰撞；遇到阻挡时会滑动或自动停止，不会无限卡住。
- 三个地标都提供独立场景入口演示。

当前版本聚焦世界地图体验，独立地点内部场景使用轻量入口面板演示。
