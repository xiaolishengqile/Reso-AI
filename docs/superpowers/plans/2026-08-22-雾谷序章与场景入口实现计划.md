# 雾谷序章与场景入口实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现主岛雾谷老人序章、三项必填旅人记录、十六型人格初始计分，并把爬山岛改为确认入口后才进入剧情。

**Architecture:** 用户画像、雾谷剧情、雾谷进度、渲染和世界地图入口各自独立。世界地图通过通用场景控制器暂停输入和分发场景，不读取对白或计分细节；爬山入口使用“确认后进入外部剧情”，完成解锁仍只由爬山尾声触发。

**Tech Stack:** 原生 JavaScript 模块、HTML、CSS、Canvas、本地存储、Node 内置测试、Vite。

**Spec:** `docs/superpowers/specs/2026-08-22-雾谷序章与场景入口设计.md`

## Global Constraints

- 昵称、留言、十六型人格全部必填。
- 十六型人格只能从固定十六项中选择。
- 类型字母对应侧基线 60，另一侧 40。
- 老人选择只修正外向—内向维度：A ±10、B ±4、C ±7、D ±12。
- 第一次完成的雾谷记录是正式画像，普通重看不得覆盖。
- 爬山入口按钮只进入剧情，不能推进完成状态或解锁顺序。
- 爬山尾声完成后才解锁工作岛。
- 不增加运行时依赖；文件按画像、剧情、进度、渲染、入口职责拆分。

export function validateTravelerRecord({ nickname, message, mbtiType } = {}) {
  const normalized = {
    nickname: String(nickname ?? "").trim(),
    message: String(message ?? "").trim(),
    mbtiType: String(mbtiType ?? "").trim().toUpperCase(),
  };
  return {
    value: normalized,
    errors: {
      nickname: normalized.nickname.length >= 1 && normalized.nickname.length <= 20 ? "" : "昵称需为 1 至 20 个字符",
      message: normalized.message.length >= 1 && normalized.message.length <= 80 ? "" : "留言需为 1 至 80 个字符",
      mbtiType: MBTI_TYPES.includes(normalized.mbtiType) ? "" : "请选择一种有效的十六型人格",
    },
  };
}
