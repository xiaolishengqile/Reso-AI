# Mountain Video Story Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将爬山岛改为全屏视频/图片推进，并在每段媒体结束后显示雾谷式画像问题。

**Architecture:** 新建独立媒体目录模块，剧情数据只负责问题和画像信息，场景控制器只负责媒体播放状态与答题状态。原生视频和图片共用同一底部问题面板，不新增依赖。

**Tech Stack:** 原生 JavaScript、HTML 视频/图片元素、CSS、Node.js 内置测试运行器。

**Spec:** `docs/superpowers/specs/2026-08-23-爬山视频剧情重构设计.md`

## Global Constraints

- 男女玩家使用同一套媒体素材。
- 不显示文字旁白或选择后的文字反馈。
- 问题仅在视频结束或图片显示后出现。
- 缺少视频的回家消息与城市顿悟必须使用项目内图片。
- 不新增第三方运行时依赖。
- 所有提交信息使用中文。
