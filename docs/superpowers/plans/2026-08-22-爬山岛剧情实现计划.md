# 爬山岛剧情实现计划

> **给执行代理：** 必须使用测试驱动开发。任务一至任务三文件互不重叠，可使用并行代理；任务四必须在前三项完成并通过审查后执行。

**目标：** 将当前爬山岛的轻量完成面板替换为带角色动画、七组剧情选择、画像证据保存和进度恢复的完整独立场景。

**架构：** 剧情内容、进度证据、画布渲染三部分互不依赖并行实现，最终由场景控制器组合。世界地图只通过进入、完成、关闭三个回调接入剧情，不包含任何爬山对白和画像规则。

**技术栈：** 原生浏览器模块、二维画布、原生对话与按钮、浏览器本地存储、原生测试运行器、前端构建工具。

**设计依据：** `docs/superpowers/specs/2026-08-22-爬山岛剧情与画像采集设计.md`

## 全局约束

- 保留附件现有七组画像选择，不新增第八组画像问题。
- 玩家选择男生时匹配女生同行者，选择女生时匹配男生同行者。
- 用户不控制场景内角色移动，剧情按动画、对白、选择、反馈、下一阶段推进。
- 暴雨后的登顶、避雨、下撤是行动决定，不计入画像证据。
- 单次选择只形成阶段性证据，不向用户显示人格结论。
- 首次游玩保存正式证据；重复游玩不得覆盖首次正式证据。
- 当前只使用浏览器本地存储，不接入大模型或远程服务。
- 不增加运行依赖，不生成或提交构建目录。

## 文件结构

- `src/scenes/mountain/storyContent.js`：只保存剧情阶段、选项、分析、指标和局部反馈。
- `src/scenes/mountain/story.js`：提供剧情查询、角色配对、文本适配和配置校验。
- `src/scenes/mountain/progress.js`：处理首次证据、恢复、重玩和本地保存。
- `src/scenes/mountain/mountainRenderer.js`：绘制咖啡馆、大山、公寓、天气、角色和动作。
- `src/scenes/mountain/createMountainScene.js`：组合剧情、进度、渲染与页面交互。
- `src/scenes/mountain/mountainScene.css`：独立场景布局与选择界面样式。
- `index.html`：提供爬山场景所需的语义化页面节点。
- `src/main.js`：创建场景并连接世界地图。
- `src/game/createGame.js`：将爬山岛入口转交给外部场景回调，暂停地图输入并在完成后解锁。

- [ ] **步骤一：先写首次证据、防重复与重玩保护的失败测试**

```js
import test from "node:test";
import assert from "node:assert/strict";
import {
  createMountainProgress,
  recordMountainSelection,
} from "../src/scenes/mountain/progress.js";

const stage = {
  id: "invitation",
  recordsEvidence: true,
  scene: "cafe",
};
const option = {
  id: "planned",
  text: "先确认天气和路线",
  analysis: "偏好可控的冒险",
  dimensions: ["规划意识", "风险偏好"],
};

test("首次选择只生成一条正式画像证据", () => {
  const initial = createMountainProgress("boy");
  const once = recordMountainSelection(initial, stage, option, {
    elapsedMs: 800,
    companionMood: "expectant",
    answeredAt: 1000,
  });
  const twice = recordMountainSelection(once, stage, option, {
    elapsedMs: 900,
    companionMood: "expectant",
    answeredAt: 1100,
  });
  assert.equal(twice.officialEvidence.length, 1);
  assert.equal(twice.answers.length, 1);
});

test("重复游玩不会覆盖首次正式画像证据", () => {
  const completed = { ...createMountainProgress("girl"), completed: true };
  const replay = createMountainProgress("girl", completed);
  const selected = recordMountainSelection(replay, stage, option, {
    elapsedMs: 500,
    companionMood: "expectant",
    answeredAt: 2000,
  });
  assert.equal(selected.isReplay, true);
  assert.deepEqual(selected.officialEvidence, completed.officialEvidence);
});
```
