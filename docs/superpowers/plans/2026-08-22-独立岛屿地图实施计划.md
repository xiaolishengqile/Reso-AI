# 独立岛屿地图实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan.

**目标：** 将世界地图改为十岛独立图层，以明显云层覆盖七座后续岛，并在角色移动时启用近景跟随。

**架构：** 配置层保存岛屿、桥梁、可行走区与云覆盖；镜头系统只负责坐标变换；渲染器只负责分层绘制；游戏主循环组合输入、移动、进度和渲染。

**技术栈：** 原生画布、现有模块化游戏循环、内置图像生成、现有 Node 测试与 Vite 构建。

**规格：** docs/superpowers/specs/2026-08-22-独立岛屿与近景镜头设计.md

**全局约束：** 保持当前功能分支与工作树隔离；不增加新运行依赖；先写失败测试再改实现；每个提交都保持可运行。
