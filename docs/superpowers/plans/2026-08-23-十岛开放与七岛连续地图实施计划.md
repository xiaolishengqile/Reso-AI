# 十岛开放与七岛连续地图实施计划

> **执行要求：** 使用测试驱动方式逐项实现，先确认测试因缺少目标行为而失败，再写最小实现。整个计划在当前功能分支内执行，不启用子任务代理。

**目标：** 开放十座世界岛屿，为七座后续剧情岛加入连续地图、自动移动和视频式分段问答，并让心愿岛依据七岛四十二题生成画像。

**架构：** 世界地图把通行状态与完成状态分离；岛内地图目录提供素材和路线，通用剧情控制器驱动移动、提问、反馈状态机，渲染器只处理镜头、场景图和角色。画像输入继续复用统一证据结构，但仅收集七座通用剧情岛。

**技术栈：** 原生 JavaScript、Canvas 二维画布、CSS、Vite、Node.js 内置测试运行器。

**设计说明：** `docs/superpowers/specs/2026-08-23-十岛开放与七岛连续地图设计.md`

## 全局约束

- 不修改爬山岛岛图、剧情、题目和内部交互。
- 不增加运行时依赖和网络请求。
- 七座剧情岛沿用现有四十二题及证据字段。
- 剧情文字和问题的推进方式复用雾谷入口的地图内底部对话节奏。
- 新世界岛图必须透明背景；新岛内地图不得包含人物或文字。
- 所有新增用户可见文案使用中文。
