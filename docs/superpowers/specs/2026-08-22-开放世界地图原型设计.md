# 开放世界地图原型设计

## 目标

在电脑浏览器中实现一张可探索的二维半开放世界地图，验证以下核心体验：

- 地图具有参考图中的柔和手绘配色、浮空大陆、山地、河流、森林与遗迹层次。
- 玩家可使用方向键或 `W/A/S/D` 在地图上连续移动。
- 正交相机平滑跟随玩家，保持俯视斜角的二维半观感。
- 玩家靠近地点后可点击进入入口；第一版仅展示“场景建设中”的反馈。

## 第一版范围

### 包含

- 一块主要可行走大陆与数块用于丰富构图的浮岛。
- 山峰、森林、遗迹、湖泊、河流、桥梁、云层与远景装饰。
- 一个低多边形角色、基础行走动画与阴影。
- 键盘移动、地形边界约束、障碍碰撞和地点距离判断。
- 地点悬停高亮、靠近提示、点击反馈和地图说明界面。
- 电脑宽屏自适应与浏览器尺寸变化处理。

### 不包含

- 独立地点内部场景。
- 手机虚拟摇杆与触摸操作。
- 战斗、任务、存档、联网、音频和程序化无限地图。
- 后端服务及美术资源管理平台。

## 技术方案

沿用参考项目的轻量技术选型：

- `Three.js`：浏览器三维渲染库，负责场景、正交相机、光照、模型、射线点击与渲染。
- `Vite`：前端构建工具，负责开发服务和生产构建。
- 原生 `JavaScript` 模块：实现地图配置、输入、移动、交互与运行循环。
- 浏览器原生界面与样式：实现标题、提示卡、按键说明和地点反馈。
- `node:test`：验证与三维渲染无关的移动和地点判断逻辑。

不复制参考项目完整的关卡系统，只复用其正交相机、渲染循环、输入控制和资源拆分思路，避免原型承担无关复杂度。

## 视觉设计

### 构图

- 主大陆横向展开，中央道路连接山峰、森林和古代遗迹。
- 河流从山地流向湖泊，以桥梁形成明显的探索路径。
- 周边浮岛和缓慢漂移的云层强化空中世界感，但不作为第一版可行走区域。
- 地点使用高低差与剪影区分，不依赖大量文字标注。

### 风格

- 使用米白、浅绿、湖蓝、陶土棕与低饱和紫色作为主色。
- 地形由不规则低多边形几何体构成，避免真实写实材质。
- 关键模型叠加深棕色细描边，模拟参考图的手绘轮廓。
- 页面背景使用天空渐变、纸张噪点和边缘暗角，补足插画质感。
- 只为玩家、地点和关键地形启用阴影，控制性能成本。

## 地图与交互

地图地点由精简配置描述：标识、名称、位置、交互半径、颜色和简介。第一版提供三个地点：云脊山、风语林、星痕遗迹。

输入方向经归一化后转换为平面速度；每帧先计算候选位置，再依次执行世界边界约束和圆形障碍碰撞。相机通过线性插值跟随玩家，避免生硬跳动。

鼠标移动时使用射线检测地点模型。地点进入范围且被点击后，显示入口反馈；范围外点击时提示玩家先靠近。地点模型的高亮、提示卡和点击行为都读取同一份地点配置。

## 模块边界

- `src/main.js`：启动应用并连接各模块。
- `src/config/world.js`：保存地图尺寸、地点和障碍等静态配置。
- `src/world/createWorld.js`：创建地形、水体、道路、建筑、植被与云层。
- `src/entities/createPlayer.js`：创建角色并更新行走表现。
- `src/systems/createInput.js`：采集键盘输入，不直接修改场景。
- `src/systems/movement.js`：纯函数计算移动、边界和地点距离。
- `src/game/createGame.js`：负责主循环、相机跟随、射线交互和界面状态。
- `src/styles.css`：负责页面界面和插画质感。

渲染对象创建、纯业务计算、输入采集与界面状态彼此分离，后续增加独立地点场景时不需要改写地图移动逻辑。

## 数据流

1. 输入模块读取键盘方向。
2. 游戏循环将方向、时间增量和当前位置交给移动模块。
3. 移动模块返回经过边界与障碍处理的新位置。
4. 玩家对象更新位置与行走动画，相机平滑跟随。
5. 交互模块根据玩家距离和鼠标射线确定当前地点。
6. 界面根据当前地点显示靠近提示或入口反馈。

## 异常与兼容处理

- 浏览器无法创建三维渲染环境时，显示明确的兼容性提示。
- 每帧时间增量设置上限，避免切换标签页后角色瞬移。
- 浏览器尺寸变化时更新正交相机范围与渲染尺寸。
- 方向键阻止页面滚动，失去窗口焦点时清空按键状态。
- 地点或配置缺失时跳过该对象并保留其余地图运行。

## 验证标准

- 开发服务可在电脑浏览器打开且无控制台错误。
- 方向键与 `W/A/S/D` 均可控制角色，斜向速度不高于直线速度。
- 玩家不能离开主大陆范围或穿过山体等障碍。
- 相机会持续平滑跟随玩家，页面缩放后构图仍完整。
- 三个地点均可悬停高亮；只有玩家进入范围后才能触发入口反馈。
- 自动测试通过，生产构建成功。
- 使用桌面宽屏截图检查层次、配色、提示可读性与参考风格的一致性。

## 后续扩展

下一阶段可将地点入口连接到独立场景运行器，并复用同一套地点配置。只有在地图规模或美术复杂度确实增长后，再引入模型文件、纹理图集、地图分块和资源加载器。
