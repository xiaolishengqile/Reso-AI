# 独立岛屿与近景镜头设计

## 目标

将当前一张整体底图拆成可独立替换的岛屿图层，保留“家庭 → 爬山 → 工作”的顺序解锁，并预留七座后续岛屿。玩家移动时进入近景跟随，停止后回到全图概览。

## 地图分层

1. 海天背景：画布绘制渐变云海，不与任何岛屿素材绑定。
2. 岛屿图层：家庭岛、爬山岛、工作岛分别使用透明底图片，各自拥有位置、尺寸、碰撞和交互配置。
3. 桥梁图层：桥梁与岛屿分离，使用独立配置绘制，解锁时只切换通行状态。
4. 云层：锁定岛屿上方绘制高不透明度多层云团，云层边界大于岛屿占位，保证场景不泄露。
5. 角色与交互层：角色、目标点、地点光圈位于最上层。

## 岛屿数据

地图共配置十座岛屿。前三座有实际场景图片和入口；后七座只保留编号、占位和云层，不提前编造场景内容。每座岛的图片路径独立，更换某一座岛时不需重新生成其他图片。

## 解锁规则

- 家庭岛是出生地，始终可进入。
- 爬山岛是第一个目标，初始可前往。
- 工作岛只在完成爬山后解锁。未解锁时，桥梁必须在角色半径范围内完整阻断，不能从侧面绕过。
- 后七座在本原型中不解锁，仅表达世界会继续展开。

## 镜头规则

- 静止：整张地图完整显示在视口内。
- 移动：镜头平滑放大到概览比例的两倍，并跟随玩家。
- 边界：镜头在地图四周限制位移，不露出空白区域。
- 交互：鼠标点击始终使用当前镜头反算地图坐标。

## 验收标准

- 页面不再引用整张串联底图。
- 三座已知岛屿均为独立透明图片，任意一张可单独替换。
- 概览中可看到十个岛屿位置，后七座被明显云团完全覆盖。
- 移动时角色和周边场景明显放大，停止后平滑返回概览。
- 工作岛未解锁时不存在绕行路径，解锁后可正常通过。
